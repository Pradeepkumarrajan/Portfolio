# Pradeep Kumar R: Portfolio (React)

## Run locally
    npm install
    npm run dev

## Customize
- All text (bio, email, experience, projects, skills): `src/data.js`
- Your photo: `public/photo.jpg` (portrait, about 800x1000)
- Colors and fonts: top of `src/styles.css`

## Publish on GitHub Pages
1. Create a new GitHub repo named `portfolio` (public) and push this folder to the `main` branch.
2. Repo Settings > Pages > Source: **GitHub Actions**.
3. Wait about a minute. Your site is live at
   `https://pradeepkumarrajan.github.io/portfolio/`
4. Put that link in your resume and on your GitHub and LinkedIn profiles.
